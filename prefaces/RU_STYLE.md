dictionary's Russian preface edition — follow them before inventing new ones.

## 1. The register: deliberately archaised — do not de-archaise

The translation renders Monier-Williams's 1899 Victorian scholarly prose in a
deliberately archaised Russian (« разумею », « посему », « силясь явить », « суть »).
This is a **choice, not a defect** (H1763 verification ruling, 27-07-2026): the
register matches the source's period and the Russian Indological tradition of
Коссович and Минаев. An editing pass may repair *inconsistency*, terminology
drift, and footnote defects; it may **not** modernise the diction.

## 2. Follow-source primacy

The English page files (`mwprefNN.md`) are the source of record; the print scan
(`scans/`) is the arbiter above both. Concretely:

- **Italics.** RU mirrors the EN file's italic markup span-for-span (verified
  29/29 files, equal counts). Do not add or drop emphasis.
- **`&c.`** stays verbatim only where EN *cites it as a dictionary symbol*
  (pp. xvii–xviii, `mwpref14`–`15`: « употребление символа &c. »); as plain
  prose etcetera it is rendered « и т. д. » (so already on p. xii).
- **Layout.** Signature-line double spacing, `[стр. NN]` page markers, and the
  `----` footnote separator follow the EN file.
- **Punctuation** inside running Russian prose is the translator's (Russian
  rhetorical-question syntax may differ from EN); footnote *markers* are not
  punctuation and follow print (§ 5).

## 3. Terminology rulings

| EN trigger | Russian | Reason |
|---|---|---|
| Root (technical) | корень | Established; MW's own gloss of *Dhātu* |
| *Dhātu* | *Dhātu* (Latin, italic) | MW cites it as a technical term; follow-source |
| Āryan | арийский | MW's deliberate term for the family; never silently replaced |
| Indo-European | индоевропейский | MW introduces it as the *later* name — the арийский/индоевропейский distinction is his, so the two are never interchangeable |
| Semitic | семитический | Archaic form, register-consistent; unified from mixed семитский/семитический (12 occurrences, pp. xxiii–xxviii) |
| Shemitic | симитический | One-off wordplay on Сим (Genesis 10), p. xii note ² — keep |
| structure (of a language) | строение | Dominant rendering (4×); unified from one строй (p. viii). «строй» stays where EN has a different head (e.g. graphic *system*, p. xxviii) |
| dialect / vernacular | наречие | Archaic register (pp. vii, xii); unified from one диалект (p. xxvi) |
| Vedic | ведийский | Already uniform — recorded to prevent drift to ведический |
| Buddhist | буддийский | Already uniform (never буддистский) |
| e.g. | напр. | Dominant follow-source mapping; unified (2 spelled-out outliers, pp. xvi, xxviii) |
| for example / for instance | например | Spelled out, matching the spelled-out EN |
| that is (to say) | то есть | Spelled out; « т. е. » not used in preface prose |
| Zand / Zend | занд / зенд | Follows EN's own alternation verbatim (p. xii) |

## 4. Transliterated Sanskrit inside Russian sentences — the two-register rule

1. **Cited terms, headwords, titles in apparatus context** — Latin IAST exactly
   as in EN, with EN's italics: *samskaraṇa*, *vyākaraṇa*, *Dhātu*,
   *prāṇa-pratishṭhā*, `RV.` &c. In apparatus discussion a work name stays
   Latin next to its siglum (p. xviii: « начиная с Ṛig-veda » beside `RV.`).
2. **Assimilated realia in running prose** — plain Cyrillic, no macrons, no
   hybrid letters: пали, пракрит, брахманы, Упанишады, сутры, шастры, Пураны,
   Ригведа, ардха-магадхи, удатта, сварита, арийский.
3. **Script names** — Latin with diacritics, following EN: Nāgarī,
   Deva-nāgarī, Brāhma, Brāhmī, Kharoshṭhī.

**Banned: hybrid Cyrillic-with-macron forms** (нāгарӣ, Брāхманами, пāли,
āрийскому, Сӯтрами, мāгадхӣ) and mixed-script tokens (Кātyāyana with Cyrillic
К). The H1763 pass removed all 25 (pp. xix–xxv, xxix, xxxi); pages xii and
xxvi–xxix were already clean and set the pattern.

## 5. Footnotes

- Markers are superscript digits (¹²³…), tight to the preceding word (no
  space), before following punctuation, in both editions.
- Every marker resolves to a note **in the same page file**, and vice versa —
  with two print-faithful exceptions: a note may be *referenced twice* from the
  body (p. xiv: two ¹), and a note begun on one page continues on the next
  under `[сноска N, продолжение со стр. NN]` (pp. ix–x).
- The scan is the arbiter of marker position and number. The H1763 pass
  repaired seven pages against print (ix, xii, xiii, xviii, xix, xxiv, xxv)
  in both EN and RU; the defect classes were dropped markers, cascaded
  renumbering, a note merged into its neighbour, and OCR `?` for `²,`.
- Table notes use the print's own `*` / `§` signs (p. xxvii) — do not
  renumber them into the digit sequence.

## 6. Mechanical rules carried over

- **No ё** — write е everywhere except standalone «всё»/«Всё» (MG ruling,
  applied to these files by H543, commit `bf5a09a`). Same rule as pwg_ru
  [RU_STYLE_MECHANICAL.md](https://github.com/gasyoun/SanskritLexicography/blob/master/RussianTranslation/pwg_ru/RU_STYLE_MECHANICAL.md) R1.
- UTF-8, no BOM; markdown lint-clean; YAML frontmatter of each page file
  (`source_scan` / `source_page` / `translation_of`) stays intact.
