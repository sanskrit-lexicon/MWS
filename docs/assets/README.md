# docs/assets — README visuals

_Created: 05-11-2026 · Last updated: 05-11-2026_

The three committed static SVGs embedded in the repository [README](https://github.com/sanskrit-lexicon/MWS/blob/master/README.md) ("Join the proofreading"). No external badge services, no client-side rendering; entry text carrying IAST diacritics is drawn as vector paths, so nothing depends on the viewer's fonts.

| File | What it is | Source | Refresh |
|---|---|---|---|
| [`pipeline.svg`](https://github.com/sanskrit-lexicon/MWS/blob/master/docs/assets/pipeline.svg) | How a correction travels: printed dictionary → `csl-orig` `v02/<dict>.txt` → generated XML → web/API → corrections loop | hand-authored, dictionary-independent | only when the pipeline itself changes |
| [`progress-mw.svg`](https://github.com/sanskrit-lexicon/MWS/blob/master/docs/assets/progress-mw.svg) | MW corrections recorded to date (9,638 events; OBS-T 2014-03-18–2026-05-30; org snapshot 2026-09) | generated by [csl-observatory `tools/render_readme_visuals.py`](https://github.com/sanskrit-lexicon/csl-observatory/blob/main/tools/render_readme_visuals.py) from the committed OBS-T snapshot | monthly, riding the correction-batch PR — regenerate, never hand-edit |
| [`correction-example.svg`](https://github.com/sanskrit-lexicon/MWS/blob/master/docs/assets/correction-example.svg) | One real correction, before and after: `mud` (MW L=165450), `(aor. amumudat)` → `(aor. amūmudat)`, printed p. 822 col. 2 from the source metaline `<pc>822,2`; record = [csl-corrections batch_20240616 case 688](https://github.com/sanskrit-lexicon/csl-corrections/blob/main/batch_20240616/dictionaries/mw/batch1.txt) | one-off generator [`src/make_correction_example.py`](https://github.com/sanskrit-lexicon/MWS/blob/master/docs/assets/src/make_correction_example.py) (Arial outlines → paths, needs fontTools + macOS system Arial) | only to feature a different example entry |

To refresh the progress card:

```bash
python ../csl-observatory/tools/render_readme_visuals.py --dict mw --out docs/assets/progress-mw.svg
```

The card is byte-identical for the same committed snapshot; the commit that refreshes it should ride the same PR as the snapshot it cites.
